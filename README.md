# Обратная связь КАДР

[Открытая тема вопросов и сообщений об ошибках](https://github.com/ultrozing-ops/kadr-feedback/issues/1). Укажите версию приложения и шаги, после которых возникает проблема. Сообщения и вложения в теме доступны всем.

## Рабочий чат

Используйте `https://kadr-feedback.pages.dev/` как адрес в `feedback-source.json`. Коды выдаёт владелец проекта. Список участников с открытым чатом доступен по действующему коду; сервер удаляет истёкшие отметки при получении очередного обновления списка.

## Развёртывание

`worker.mjs` разворачивается через Cloudflare Pages Direct Upload под именем `_worker.js`. Переменные Production: `GITHUB_REPO`, `GITHUB_ISSUE`, `GITHUB_AUTHOR_ID`. Секреты: `GITHUB_TOKEN`, `KADR_AUTHOR_CODE`, `KADR_MEMBER_CODES`. Привязка `CHAT_PRESENCE` указывает на D1-базу присутствия. Коды коллег хранятся списком через пробел. После изменения переменных или привязок требуется новое развёртывание.
